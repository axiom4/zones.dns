HTTP / HTTPS Ad & Popup Proxy

Built-in filtering proxy (manage.py runproxy) assigned automatically to clients via DHCP WPAD (option 252 + wpad.<domain>). Blocks ad and tracker domains from the Blacklist, strips ad banners and popup scripts, and supports both standard HTTPS CONNECT and optional HTTPS MITM page inspection.

Proxy server & DHCP auto-discovery (WPAD)
