HTTP / HTTPS Ad & Popup Proxy

Built-in filtering proxy (manage.py runproxy) assigned automatically to clients via DHCP WPAD (option 252 + wpad.<domain>). Blocks ad and tracker domains from the Blacklist, strips ad banners and popup scripts, and supports both standard HTTPS CONNECT and optional HTTPS MITM page inspection.

Proxy server & DHCP auto-discovery (WPAD)

When enabled, DHCPv4 sends option 252 (WPAD) and the DNS daemon resolves wpad.<domain> to the server IP. macOS / iOS: enable Auto Proxy Discovery in System Settings → Wi-Fi → Details… → Proxies, or install the one-click Apple Profile (.mobileconfig) above (sets up both the PAC proxy and the Root CA).

External ad-block lists

Lists in Adblock Plus / EasyList syntax, downloaded by the proxy every day. It applies the domain rules (||domain^), the exceptions (@@||domain^) and the rules that hide page elements (##selector); URL fragments and rules with browser-only options are skipped.
