Domain audit

Gathers public information about a domain or host and flags the most common problems: DNS, mail, registration, certificate and web headers.

The server queries the domain and its name servers from the Internet (DNS, RDAP, HTTPS on port 443 and HTTP on port 80; with the deep analysis also the public certificate logs). Non-public addresses are never contacted. Analyse your own or public domains.
